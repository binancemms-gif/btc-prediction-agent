# BTC Prediction Agent

A simple website-based prediction agent for short-term Bitcoin (BTC) up/down forecasts (5min / 10min).

Inspired by [Apache PredictionIO](https://github.com/apache/predictionio) for building predictive engines.

## Features (planned)
- Live price fetching from Binance / CoinGecko
- Short-term momentum & range analysis
- Crowd sentiment (prediction market style)
- Logging predictions (Notion integration or local)
- Web UI for live predictions and history
- Accuracy tracking over time

## Current Status
Starter repository created. Initial Notion logging of BTC snapshots is active in parallel.

## Next Steps
1. Build FastAPI backend with prediction logic
2. Simple React/Next.js frontend
3. Price API integrations
4. Optional Notion sync for logs

## Disclaimer
Not financial advice. Ultra-short-term crypto predictions are highly speculative and close to random with minor momentum edges.
